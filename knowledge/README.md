# knowledge/

Versioned consultation handbook for the agent fleet: brand, proof, funding,
values, and process reference material that agents read but do not generate.
Declare a fact once here, point at it everywhere else, never copy it into a
prompt or template.

## Index

- `credentials.yml`: the credentials A+ holds (NSSA Tutoring Program Design
  Badge), the canonical claim string, term window, usage rules, and the
  `public_ready` gate. Read via `scripts/credentials.py`.
- `eos/README.md`: quarterly rocks, seats, and the Organizational Excellence
  work; who owns retention and quality this quarter.
- `journey/README.md`: the customer journey communication playbook, first
  touch to renewal, with the pre-send checklist
  (`journey/00-pre-send-checklist.md`) every agent and human passes before
  contacting a family, a teacher of record, or a tutor. Stages are readable by
  agents only when marked REVIEWED.

Still to seed: the consultation handbook, brand canon (the brand kits live in
`marketing/skills/` today), proof and case-study reference, funding context.
