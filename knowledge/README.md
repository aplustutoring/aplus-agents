# knowledge/

Versioned consultation handbook for the agent fleet — brand, proof, funding, and
product reference material that agents read but do not generate.

## Contents

- **`CUSTOMER_JOURNEY.md` — the fleet's canonical customer journey map.**
  The master map of the B2C family journey: the nine stages, locked
  consultation doctrine (trust-first/money-last, pricing never read aloud,
  the "what school" silent qualifier, TOR capture, earned free trial),
  charter/private/test-prep ICPs, and the agent master list. Any agent or
  session that needs journey, consultation-play, or ICP context reads this
  file first. Rubrics and coaching prompts (e.g. `ops/call_agent/rubric.md`)
  must stay consistent with it.
